# CHANCES landing pages

Run `npm run dev`, then visit http://localhost:5173.

- `index.html`: complete landing page from `landing page.jpg`.
- `early-access.html`: dedicated signup design from `landing page 2.jpg`.
- Artwork is extracted from the supplied references to retain the original branding. The hero is reference artwork with an accessible description and a linked CTA; other page content is HTML.
- Responsive layouts, native form validation, FAQ accordions, and informational dialogs are included.
- Signup is a local preview: form details are saved only in browser localStorage. Connect a backend or mailing-list service before accepting live registrations. Official privacy, terms, and contact content must also be supplied.

No external dependencies or build step are required.
